# 論文対訳ビューア

英語の理系論文（PDF）を日本語に翻訳し、原文と日本語訳を並べて読むためのアプリです。翻訳は手元のPCで Claude CLI を使って行い、できた訳は Web の「共有ライブラリ」に公開して、パスワードを知っている人だけが読めるようにできます。

## できること

- **レイアウトを保った日本語PDF**: 原文PDFの段落の位置に日本語を描き直した PDF を作ります。数式・図の中の文字・参考文献・コードは訳さずに元のまま残し、表はセルごとに訳して形を変えません。
- **対訳表示**: 「PDFで比較」タブでは原文PDFと日本語PDFを左右に並べます。文をクリックすると、もう一方の対応する文がハイライトされます。「テキスト対訳」タブでは文単位の対訳を読めます。
- **訳語をそろえる**: 翻訳の前に論文全体から用語集を作り、論文の中では同じ訳語を使います。公開した論文の用語は「用語ベース」にたまり、次の論文でも同じ訳語を使います。
- **訳を直す**: 段落ごとに「ここをこう直して」と指示して訳し直せます。用語集の訳語を直すと、論文全体の訳と日本語PDFが置き換わります。公開済みの論文も、下書きに戻して直してから公開し直せます。
- **Claude の利用上限で止まらない**: 上限に達すると一時停止し、上限が戻ったら続きから自動で再開します。

## しくみ

```
┌──────────── 翻訳する人のPC ────────────┐        ┌──────── Web ────────┐
│ ローカルアプリ (server.js, localhost:3000) │  公開   │ 閲覧用Web (Vercel)  │
│   PDF解析 → 用語集 → 翻訳 → 日本語PDF     │ ─────▶ │   public/ + api/    │
│   翻訳は各自の Claude CLI を呼び出す       │        │         │           │
│   下書きは data/ に保存                   │        │  Cloudflare R2      │
└──────────────────────────────────────────┘        │  (PDF・訳・用語ベース) │
                                                     └─────────────────────┘
```

- **ローカルアプリ**（`server.js`, `lib/`）: PDF を `pdfjs-dist` で読み、段落・数式・図・表を分けます（`lib/pdfLayout.js`）。翻訳は `claude -p` を直接呼び出します（`lib/claudeTranslate.js`）。翻訳の方針は `.claude/skills/translate-sci-paper/SKILL.md`、モデルと全論文で固定の訳語は `translation.config.json` で決めています。各自の Claude の個人設定は翻訳に使われないので、誰が翻訳しても同じ設定になります。
- **閲覧用Web**（`public/`, `api/`）: ローカルアプリと同じ画面を Vercel で配信します。ファイルは非公開の R2 バケットに置き、ブラウザは期限付きの署名付きURLで直接取得します。
- 翻訳の流れ: 用語集を作る → 訳さない部分を機械的に除き、残りを約3000字ずつに分ける → 3つずつ並行して翻訳する → 数値・引用番号・図番号の抜けや数式の欠けがある段落だけを訳し直す。

## 使い方

必要なもの: Node.js 22 以上と、ログイン済みの Claude CLI。

```bash
npm install
```

```bash
npm start
```

ブラウザで `http://localhost:3000` を開き、PDF をアップロードすると翻訳が始まります。共有ライブラリを使わなければ、ここまでで手元だけで使えます。

- 翻訳する人の準備と使い方: [docs/translator-setup.md](docs/translator-setup.md)
- 共有ライブラリ（Vercel ＋ Cloudflare R2）の立て方: [docs/sharing.md](docs/sharing.md)

## 当初の想定と今

最初の版（2026-10-20）は、**友達それぞれが自分のPCで翻訳し、共有ライブラリに持ち寄る**つもりで作りました。使いながら、**1人が翻訳して公開し、友達は読むだけ**の形に寄せてきています。

| | 当初の想定 | 今 |
|---|---|---|
| 誰が翻訳・公開するか | 友達それぞれ。各自の Claude CLI で翻訳して公開する | 主に管理する人。`PUBLISH_PASSWORD` を設定すれば、公開できるのはその人だけ（未設定なら当初どおり誰でも） |
| 公開の認証 | 1人ずつ別のアップロード用トークン | パスワード1つ（閲覧用、または公開専用） |
| 閲覧用Webに出る情報 | 公開した人の名前、いま翻訳中の論文、論文の追加方法 | 論文の一覧と本文だけの、ふつうの図書館。翻訳中の論文の表示はローカルアプリにだけ残っている |
| 公開した論文 | 上書きできない | 確認したうえで差し替えられる。下書きに戻して直してから公開し直せる |
| 手元のデータ | ローカルのライブラリが正本 | 共有ライブラリにつなぐと、そちらが正本。ローカルは下書きを作る作業場で、公開すると手元からは消える |
| 翻訳の進め方 | 部分ごとに順に訳し、訳しながら用語集に足していく | 先に論文全体の用語集を作ってから、3並列で翻訳する。論文をまたいで訳語をそろえる用語ベースがある |
| 訳文の方針 | 自然な日本語を優先し、文を分けたりまとめたりしてよい | 英文1文の中だけで組み替える（分けてよいが、まとめたり文をまたいで移したりしない）。文や修飾語の長さ、ぼかし表現・数量の言い方を細かく決めている |
| 数式・図・表 | 段落と同じように読んで訳す | 数式は元の字形のまま残す。図の中の文字は訳さない。表はセルごとに訳す |
| 失敗したとき | すぐにやり直し、だめなら「翻訳に失敗しました」 | 利用上限では一時停止して自動で再開する。失敗した段落だけを訳し直せる |

## 今後

決まっている予定ではなく、いま見えている課題と候補です。

- **PDFの読み取りを広げる**: 数式・図・表の見分け方は、実際に訳した論文（PNAS、IEEE など）に合わせて調整してきました。2段組の崩れ方や表の作り方が違う出版社のPDFでは、まだ取りこぼすことがあります。文字情報のないスキャンPDF（画像だけのPDF）には対応していません。
- **共有ライブラリの管理**: 公開した論文を Web から消す機能はなく、R2 の管理画面で消す必要があります。
- **アクセスの管理**: 閲覧は共通パスワード1つで、人ごとのアカウントや取り消しはありません。総当たり対策も、失敗時に少し待たせるだけです。読む人が増えるなら見直しが必要です。
- **テスト**: 自動テストがありません。PDF の読み取りは小さな変更で別の論文が崩れやすいので、訳した論文を使った回帰テストがあると安心です。
- **ドキュメント**: `docs/` には、友達それぞれが翻訳・公開する前提の説明や、共有済みの論文は上書きできないという古い説明が残っています。今の運用に合わせて直す必要があります。
- **ライセンス**: まだ決めていません。今は、ほかの人が使ったり改変したりすることは想定していません。

## 注意

共有ライブラリに公開してよいかは、論文のライセンスや出版社の規約によります。改変禁止（ND）のライセンスなどでは、翻訳の共有が認められないことがあります。
