# 翻訳する人の準備

論文の翻訳は、各自のPCで動くこのアプリが、各自の Claude CLI を呼び出して行います。翻訳に使う Skill・モデル・呼び出し方はアプリの中で決まっているので、誰が翻訳しても同じ設定になります（各自の Claude の個人設定は翻訳に使われません）。

## 1. 用意するもの

1. **Node.js**（バージョン 22 以上）
2. **Claude CLI**: 公式の手順でインストールし、ターミナルで一度 `claude` を起動して、自分のアカウントでログインする。翻訳の利用量は各自のプランの上限に含まれる。
3. このアプリのフォルダ（共有されたリポジトリ、または zip）

## 2. 起動

```bash
npm install
```

```bash
npm start
```

ブラウザで `http://localhost:3000` を開き、PDF をアップロードすると翻訳が始まる。翻訳は次の順に進む。

1. 用語集: 論文全体を読み、専門用語の訳語を先に決める。
2. 範囲決め: 参考文献・数式・図の中の文字・コードを訳さない部分として機械的に除き、残りを約3000字ずつに分ける。
3. 翻訳: 分けた部分を3つずつ並行して訳す。どれも同じ用語集を使う。
4. 確認: 数値・引用番号・図番号が訳から抜けた段落だけ、抜けた番号を伝えて訳し直させる。

用語集は論文の「用語集」タブで見られる。

論文をまたいで訳語を揃えるため、公開した論文の用語集は共有ライブラリの「用語ベース」に追加される（すでにある用語は上書きしない）。次の論文の用語集は、その論文に出てくる用語ベースの訳語を必ず使って作られる。下書きの「用語集」タブで「直す」を押すと、その論文の訳がすべて置き換わり、日本語PDFも作り直され、用語ベースの訳語も直した訳に変わる。

## 3. 共有ライブラリに公開する（任意）

翻訳アプリのホームにある「共有ライブラリに接続」欄に、共有ライブラリの URL と公開用パスワード（Vercel に `PUBLISH_PASSWORD` を設定していなければ閲覧用と同じ）を入れて「接続」を押す。設定はフォルダ直下の `config.local.json` に保存される（このファイルは共有しない）。共有ライブラリのURLが変わったときは、同じ欄の「変更」からURLだけ直せる（パスワードは空欄のままでよい）。Vercel の URL はデプロイごとに変わるので、Settings → Domains に出ている本番用のURLで接続しておくと直す必要がない。

アプリを再起動すると、共有ライブラリが正本になり、このアプリは「翻訳して納品する作業場」として動く。

- ホームには「自分の下書き（未公開）」と「共有ライブラリ」が並ぶ。共有ライブラリの論文はクリックすると閲覧用のWebで開く。
- 翻訳が終わった論文は下書きになる。内容を確認して「共有ライブラリに公開」を押すと共有ライブラリに移り、このPCからは消える（同じ段落の翻訳キャッシュは残る）。不要な下書きは「削除」で消せる。
- アップロードしたPDFが共有ライブラリにすでにあれば、自分では翻訳せず、そちらを案内する。

翻訳を始めると、共有ライブラリの「いま翻訳中の論文」に自分の名前と論文タイトルが出る（公開するか、12時間たつと消える）。ほかの人が翻訳中の論文をアップロードすると「○○さんが翻訳中です」と止まるので、公開を待つか、「それでも自分で翻訳する」を押す。

## うまくいかないとき

- 「Claude CLI が必要です」と出る: ターミナルで `claude --version` が動くか確認する。動けばアプリを再起動する。
- 「Claude CLI が古い」と出る: Claude CLI を更新する。
- 翻訳が「ログインしていません」で止まる: ターミナルで `claude` を起動してログインし、もう一度アップロードする。
- 翻訳中に Claude の利用上限に達した: 翻訳は「一時停止中」になり、上限が戻る時刻にアプリが自動で続きから再開する（訳し終えた段落は訳し直さない）。アプリは起動したままにしておく。止めていても、次に起動したときに再開する。急ぐときは「今すぐ再開」を押す。
- 一部の段落が「(翻訳に失敗しました)」になった: 論文を開き「失敗した段落を訳し直す」を押すと、その段落だけ翻訳し直す。
- どの論文でも必ず同じ訳にしたい用語は、`translation.config.json` の `glossary` に `"英語": "日本語"` の形で書く。論文ごとの用語集より優先される。
- 翻訳の設定（使うモデル）は `translation.config.json`、翻訳の方針は `.claude/skills/translate-sci-paper/SKILL.md` にある。変えるときは全員で揃えるため、リポジトリ側で変更して配り直す。
